# 小魔头Galgame论坛

一个使用 Firebase 构建的现代社区论坛系统！

## 🎯 功能特点

- ✅ **多种登录方式**：支持邮箱注册和 GitHub 一键登录
- ✅ **完整的用户系统**：注册、登录、个人资料
- ✅ **论坛板块**：4大讨论板块，满足不同需求
- ✅ **帖子系统**：发布、浏览、评论
- ✅ **文件分享**：支持附件上传下载
- ✅ **管理后台**：用户管理、帖子审核
- ✅ **响应式设计**：完美适配手机、平板、电脑
- 🎨 **精美界面**：采用紫色毛笔字风格设计

## 🛠️ 技术栈

- **前端**：HTML5 + CSS3 + JavaScript
- **后端**：Firebase Realtime Database
- **认证**：Firebase Authentication
- **部署**：GitHub Pages
- **样式**：自定义 CSS + Google Fonts

## 📂 项目结构

```
├── index.html          # 首页
├── login.html          # 登录页
├── register.html       # 注册页
├── category.html       # 板块帖子列表
├── post.html          # 帖子详情
├── new-post.html      # 发布帖子
├── admin.html         # 管理后台
├── FIREBASE-DEPLOY.md # Firebase 部署指南
└── README.md          # 项目说明
```

## 🚀 快速开始

### 1. 创建 Firebase 项目
访问 [Firebase Console](https://console.firebase.google.com/) 创建新项目

### 2. 配置 Firebase 服务
- 启用 Authentication
- 启用 Realtime Database

### 3. 部署
按照 [FIREBASE-DEPLOY.md](FIREBASE-DEPLOY.md) 指南完成部署
